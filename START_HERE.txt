🖼️  VIEW VISUALIZATIONS (OPTION 1 - EASIEST!)
────────────────────────────────────────────────────────────────────────────

     ./venv/bin/python scripts/demo_visualizations.py

  2. View the images:
     open results/*.png                    (Mac)
     xdg-open results/three_layer_graph.png (Linux)
     start results\three_layer_graph.png    (Windows)

  📁 Files created in results/ folder:
     • three_layer_graph.png - Full 3-layer architecture
     • evolution_network.png - Event evolution network
     • risk_propagation.png - Risk-entity connections
     • evolution_heatmap.png - Event type matrix
     • component_breakdown.png - Method contributions
     • And 3 more...

🗄️  NEO4J BROWSER (OPTION 3 - GRAPH DATABASE)
────────────────────────────────────────────────────────────────────────────
  1. Open Neo4j Browser:
     open http://localhost:7474
     
  2. Login:
     Username: neo4j
     Password: <set in .env>

  3. Try this query:
     MATCH (e1:Event)-[r:EVOLVES_TO]->(e2:Event)
     RETURN e1, r, e2
     LIMIT 50

  Click the graph icon (top right) to visualize!

🆘 COMMON ISSUES
────────────────────────────────────────────────────────────────────────────
  Problem: "No module named 'flask'"
  Solution: Use ./venv/bin/python (not just python)

  Problem: API not connecting
  Solution: Make sure ./venv/bin/python api/app.py is running

  Problem: Neo4j not running
  Solution: ./scripts/start_neo4j.sh or docker start feekg-neo4j
